# KRCPL — Lösungen zu The C Programming Language (K&R)

Dieses Repository enthält meine (inoffiziellen) Lösungen, Programmtexte und
Experimente zu The C Programming Language von Kernighan & Ritchie (2nd
Edition).  Der Fokus liegt auf den Kapiteln 1 bis Anfang 4, inklusive aller
Übungen, kleiner Tools und Beispielprogramme.

---

## Ziel des Projekts

Das Ziel dieses Repos ist:

- eine saubere, nachvollziehbare Sammlung aller Lösungen zu erstellen

- die Beispiele aus K&R modular, kompilierbar und idiomatisch aufzubereiten

- typische C‑Techniken wie Pointer, Arrays, I/O und Modularisierung sichtbar zu
  machen

- eine Grundlage für spätere Kapitel (z. B. RPN‑Rechner in Kapitel 4) zu
  schaffen

Alle Lösungen sind eigenständig entwickelt, orientieren sich aber eng an Stil
und Philosophie von K&R.

---

## Kompilieren & Ausführen

Das Projekt enthält ein einfaches Makefile.

### Alles bauen

```
make
```

### Einzelnes Programm bauen

```
make build/exercise4-01
```

### Aufräumen

```
make clean
```

---

## Stil & Philosophie

Alle Lösungen folgen diesen Prinzipien:

- K&R‑Stil (Einrückung, Klammern, Funktionslayout)

- Minimale, aber klare Implementationen

- Keine unnötigen Bibliotheken

- Portables C (C89/C90)
